# 手势粒子照片站点

这是可直接上传到静态网站托管服务的完整版本。把此文件夹中的文件和子文件夹原样上传，确保 `index.html` 位于站点根目录。访客无需登录；托管平台需要提供 HTTPS，手机浏览器才能使用摄像头。

站点已包含照片、背景音、Three.js、MediaPipe 脚本与手势识别模型，不需要从第三方 CDN 加载运行资源。张开手掌时照片化为扩散粒子，握拳时还原清晰照片并播放背景音。

照片和音频是公开站点资源。任何拿到公开链接的人都可以查看或下载。若要删除公开内容，请在托管平台关闭站点或删除上传文件。

此文件夹中的 `vendor/three/LICENSE` 和 `vendor/mediapipe/LICENSE` 是第三方组件许可文件。
